# Internship-at-Avito-QA

## 📌 Описание

Этот репозиторий содержит тестовое задание для стажёра на QA-направление. В нём представлены решения двух обязательных частей задания, которые демонстрируют навыки тестирования, автоматизации и работы с инструментами контроля версий.

## 📂 Структура репозитория

- `task_1` – решение первого задания (единое для всех участников, проверяет базовые навыки);
- `task_2` – решение второго задания (вариант зависит от выбора участника);
- `README.md` – описание репозитория, инструкции по запуску;
- `tests/` – файлы с тестами, созданными для проверки работоспособности проекта.

## 🚀 Как запустить

### 🔹 1. Клонирование репозитория

Для начала работы необходимо склонировать репозиторий на локальный компьютер:

```bash
git clone https://github.com/LyapinVladislav/Internship-at-Avito-QA.git
cd Internship-at-Avito-QA
```

### 🔹 2. Установка необходимых библиотек и зависимостей

Для корректной работы кода требуется установка ряда библиотек. Используйте следующую команду для их установки:

```bash
pip install pytest selenium playwright

```

### 📌 Используемые технологии и инструменты:
- **Python 3.x** – основной язык программирования;
- **Pytest** – библиотека для автоматизированного тестирования;
- **Selenium** – инструмент для тестирования веб-интерфейсов;
- **Playwright** – библиотека для UI-тестирования.

### 🔹 3. Запуск тестов

После установки зависимостей можно запустить тесты, используя команду:

```bash
pytest tests/ -v
```

Эта команда выполнит все тесты, содержащиеся в папке `tests/`, и отобразит их результаты в терминале.

## 🛠 Используемые технологии

Данный проект разработан с использованием следующих технологий:
- **Python** – основной язык для написания тестов и автоматизации;
- **Pytest / Selenium / Playwright** – инструменты для тестирования веб-приложений;
- **Git / GitHub** – система контроля версий и платформа для совместной работы над кодом.
