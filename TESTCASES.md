# Тест-кейсы для доски объявлений

## 1. Создание объявления

**Предусловия:**

- Пользователь авторизован
- Открыта страница создания объявления

**Шаги:**

1. Ввести заголовок объявления
2. Ввести описание объявления
3. Загрузить изображение (необязательно)
4. Ввести цену
5. Нажать кнопку "Создать"

**Ожидаемый результат:**

Объявление создаётся и появляется в списке объявлений

## 2. Редактирование объявления

**Предусловия:**

- Пользователь авторизован
- В системе есть созданное объявление

**Шаги:**

1. Открыть страницу со списком объявлений
2. Выбрать объявление для редактирования
3. Внести изменения (например, изменить заголовок или цену)
4. Нажать кнопку "Сохранить"

**Ожидаемый результат:**

Изменения сохраняются и отображаются в объявлении

## 3. Поиск объявлений

**Предусловия:**

- Пользователь авторизован
- В системе есть несколько объявлений

**Шаги:**

1. Открыть страницу поиска
2. Ввести ключевое слово в поисковую строку
3. Выбрать параметры сортировки
4. Указать количество объявлений на странице
5. Нажать кнопку "Найти"

**Ожидаемый результат:**

Отображается список объявлений, соответствующих поисковому запросу
